What is this?

Webdesk works like an OS, allowing you to open applications in windows by clicking on the application Launchers. This is an application Window, you can try moving it arround by clicking on the title, or you can try resizing it by grabbing an edge and drag the cursor! "Normal" windows also allow you to minimise and maximise them - usually but not always, since every application can choose which buttons to have in the titlebar. When you open an application you will see it's icon appear on the bottom bar too - that's the App Dock and it allows you to multitask with multiple applications open.

How does it work?

When the user clicks on a launcher, an event is emitted and it gets iterpret into which app to open, fetching the application's index and resources. Then, the App Dock updates by displaying the icon of the opened app. When a window's close button is clicked, the window simply deletes itself. As for the system on the backend, it uses Deno, listening for incoming requests and handling the application indexing, by mapping all the different browser endpoints to the respective resource.
